# Push Automático 1.0 — 05H5: redução de trabalho descartado

CI base 45876175038 aprovada. Detector usa updateTime do chat retornado pelo servidor apenas como veto conservador: se anterior/igual à ativação ou mais antigo que 110s, não consulta a mensagem. O aplicativo QA normalmente atualiza sala e mensagem atomicamente; importações ou dados atípicos podem ser descartados, escolha deliberada de segurança. Metadado ausente/inválido não autoriza: mantém leitura canônica original. Não muda TTL, cotas reservadas ou autorização. Snapshot transacional decodifica apenas campos utilizados da mensagem e sala, sem alterar batchGet completo no fio; não é minimização de tráfego integral. Gates negativos antecipados para configuração fechada, mensagem inválida/antiga, sala divergente, bloqueio, mute, admissão/idade inválida ou nenhum dispositivo elegível evitam consultas seguintes. O plano de autorização completo permanece obrigatório para todo candidato positivo. Testes cobrem economia de leitura e revogação sem consultar dispositivos ou Auth. CI pendente. Não afirmar redução medida de CPU no runtime Free; não há runtime hospedado autorizado para teste. Orçamento global, IAM, política de latência e homologação ainda são gates. Nenhum cron, alteração de credenciais, migração D1, faturamento ou deploy. Próximo: integração de scheduled com medidor único e decisão explícita sobre viabilidade do cron antes de qualquer implantação.
