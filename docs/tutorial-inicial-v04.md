# Registro histórico — fase inicial 0.4

A fase inicial usava um ZIP de código, um script para criar o repositório privado
e APKs debug. O repositório já existe e as atualizações usam assinatura release
permanente; esses comandos de criação e instalação foram retirados da árvore atual.

Para trabalhar no projeto existente e obter a versão correta, siga o
[README atual](../README.md) e o [guia de manutenção](manutencao.md).
Não aplique ZIPs de versões antigas sobre o código atual.

O [tutorial original e demais arquivos históricos](https://github.com/josuepradodeoliveiracosta-gif/atrio-catolico-android/tree/22824fadd4c988ac24616e7bf7411823f3e3e61c)
continuam disponíveis no histórico Git. Esse registro não comprova o estado
atual do código, da infraestrutura ou do aplicativo instalado.
