# Selos e títulos — referência visual

| Categoria | Fonte | Limite |
| --- | --- | --- |
| Fundador | [Arte](../../docs/selo-fundador-arte.md) | Aparência não concede autorização |
| Padre / clero | [Revisão](../../docs/revisao-clero-v0140.md) | Exige validação e revogação pelo backend |
| Diácono | [Arte](../../docs/selo-diacono-arte.md) | Cor não concede privilégio |
| Leigo / leiga | [Documento](../../docs/selos-leigo-leiga-v0135.md) | Legibilidade e clareza |
| Moderador | [Arte](../../docs/selo-moderador-arte.md) | Permissão separada de iconografia |
| Títulos de participação | A definir por Issue | Não confundir reputação com autoridade religiosa |

Descrever variantes claro/escuro, ícones, semântica, contraste, tamanho mínimo e critérios de concessão. Novos títulos devem ter classificação: **participação**, **cargo reconhecido** ou **papel técnico**.
