# Interações animadas

Conceitos iniciais para detalhar: abertura de discussões; estados de envio de comentário; detalhe do selo de perfil; confirmação da notificação; feedback e confirmação em moderação.

Para cada proposta, registrar estados, evento, duração-alvo, easing, reversão/interrupção, foco, toque, contraste, fontes grandes, redução de movimento, desempenho e evidência do teste.

**Nenhuma animação é automaticamente incorporada ao Android** por existir nesta pasta.
